# Security

carlink runs with shell rights on the phone (through Shizuku) and shows the
phone's apps in a car, so security reports are welcome.

**Report privately:** GitHub, *Security* tab > *Report a vulnerability*
(private vulnerability reporting). Please don't open a public issue for
security problems.

In scope: the engine (`android/`, `core/`), the car page (`web/`), the
protocol (`docs/PROTOCOL.md`), and the release/deploy workflows. Useful
context: the threat model notes in `docs/qa/*/notes.md` (security reviews per
milestone).
